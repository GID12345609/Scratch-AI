# Scratch-AI

A local HTTPS bridge that connects the Scratch 3 Translate extension to an AI model through the PenguinGPT OpenAI-compatible API.

## Features

- Works with the Scratch 3 Translate extension.
- Uses PenguinGPT as the AI provider.
- Supports the `gpt-6` model.
- Provides a local HTTPS endpoint compatible with the Scratch Translate service.
- Uses a local Flask server.

## Requirements

- Windows 10/11
- Python 3.10+
- Git
- Internet connection
- PowerShell

## 1. Download the project

```powershell
git clone https://github.com/GID12345609/Scratch-AI.git
cd Scratch-AI
```

If you already have the project:

```powershell
Set-Location "D:\ScratchGrok"
```

## 2. Install dependencies

Create a virtual environment:

```powershell
py -3.10 -m venv .venv
```

Activate it:

```powershell
.\.venv\Scripts\Activate.ps1
```

Install the required packages:

```powershell
python -m pip install --upgrade pip
python -m pip install Flask requests cryptography
```

## 3. First-time HTTPS setup

Scratch-AI uses a local HTTPS server.

The project includes `generate_cert.py` for certificate generation. If the certificates have not been generated yet, run:

```powershell
python .\generate_cert.py
```

The local root CA must be trusted by Windows for the Scratch Translate hostname.

The Windows hosts file must also direct the Scratch Translate hostname to the local machine:

```text
127.0.0.1 translate-service.scratch.mit.edu
```

If the setup scripts do not configure these automatically, configure the hosts entry and install the generated root CA into Windows Trusted Root Certification Authorities.

Only trust certificates generated by your own local project.

## 4. Start Scratch-AI

Open PowerShell in the project directory:

```powershell
Set-Location "D:\ScratchGrok"
.\Run.ps1
```

If Windows asks for permission to modify system certificate or hosts settings, run PowerShell as Administrator and follow the setup instructions.

Keep the server window open while using Scratch.

## 5. Test the server

Open these URLs in a browser after starting the server and completing HTTPS setup:

Health check:

```text
https://translate-service.scratch.mit.edu/health
```

Translation test:

```text
https://translate-service.scratch.mit.edu/translate?text=Hello
```

A successful health check should return JSON similar to:

```json
{
  "model": "gpt-6",
  "ok": true,
  "provider": "PenguinGPT"
}
```

The translation endpoint should return a JSON response containing `result`.

## 7. Use with Scratch

1. Start the local Scratch-AI server.
2. Open a Scratch 3 project.
3. Add the Translate extension.
4. Use the Translate blocks.
5. Keep Scratch-AI running while using the extension.

## Troubleshooting

### Connection refused

Make sure `Run.ps1` is running and the local server has started.

### Scratch cannot connect

Check the Windows hosts entry:

```text
127.0.0.1 translate-service.scratch.mit.edu
```

Also verify that the local root CA is trusted by Windows.

### Certificate error

Check that the generated root CA has been installed in the Windows Trusted Root Certification Authorities store.

### API errors

Check your internet connection and verify that the PenguinGPT API is available.

## Security

- Do not publish `key.pem`, private keys, or private root CA files.
- Do not commit `.env` files or credentials.
- Keep generated certificates local.
- This project changes local hostname resolution. Remove the hosts entry if you no longer want to use the local bridge.
